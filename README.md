# ИИ-помощник юриста

Веб-ассистент для правового анализа жизненных и судебных ситуаций по законодательству Российской Федерации. Описываешь ситуацию своими словами — получаешь разбор с указанием конкретных норм, судебной практики, вариантов действий, рисков и сроков.

Ключевая особенность: ассистент не отвечает «по памяти» модели. Перед каждым ответом он ищет актуальные источники в интернете, загружает их и строит ответ на найденных текстах, с ссылками на каждый факт.

## Как это работает

```
вопрос пользователя
      ↓
Query Expander     один вопрос → несколько поисковых формулировок
      ↓             (норма закона / судебная практика / порядок действий)
Search             поиск в DuckDuckGo по всем формулировкам
      ↓
Crawler            загрузка страниц, очистка от «мусора», лимит объёма
      ↓
LLM (GigaChat)     ответ строго по найденным источникам, с ссылками [1], [2]
      ↓
ответ + список источников
```

Такой подход (RAG) защищает от выдуманных статей и несуществующих решений судов: если ответа нет в найденных фрагментах, ассистент честно об этом скажет.

## Технологии

| Слой | Что используется |
|---|---|
| Веб-фреймворк | Django 5.1 |
| Генерация ответа | GigaChat (Сбер), задел под YandexGPT |
| Поиск | ddgs (DuckDuckGo и другие движки) |
| Извлечение текста | trafilatura, pypdf, python-docx, Tesseract OCR (опционально) |
| Хранение диалога | сессии Django (SQLite) |
| Интерфейс | HTML + CSS + vanilla JS, AJAX без перезагрузки страницы |

## Установка

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/ev-g-hash/Al-pihta.git
   cd Al-pihta
   ```

2. **Создать виртуальное окружение и установить зависимости**
   ```bash
   python -m venv venv
   venv\Scripts\activate          # Windows
   # source venv/bin/activate     # Linux / macOS
   pip install -r requirements.txt
   ```

3. **Настроить ключи**
   ```bash
   copy .env.example .env         # Windows
   # cp .env.example .env         # Linux / macOS
   ```
   Затем открыть `.env` и вписать данные GigaChat (см. таблицу ниже).

4. **Применить миграции** (создать таблицы сессий)
   ```bash
   python manage.py migrate
   ```

5. **Запустить**
   ```bash
   python manage.py runserver
   ```
   Открыть http://127.0.0.1:8000/

## Настройка `.env`

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `LLM_PROVIDER` | Провайдер модели: `gigachat` или `yandex` | `gigachat` |
| `GIGACHAT_AUTH_KEY` | Готовый «ключ авторизации» из личного кабинета | — |
| `GIGACHAT_CLIENT_ID` + `GIGACHAT_CLIENT_SECRET` | Альтернатива ключу: токен собирается автоматически | — |
| `GIGACHAT_SCOPE` | Область доступа: `GIGACHAT_API_PERS`, `GIGACHAT_API_B2B`, `GIGACHAT_API_CORP` | `GIGACHAT_API_PERS` |
| `GIGACHAT_MODEL` | `GigaChat-2`, `GigaChat-2-Pro`, `GigaChat-2-Max`, `GigaChat-3-*` | `GigaChat-2` |
| `MULTI_QUERY` | Делать из вопроса несколько поисковых запросов (`True`/`False`) | `True` |
| `SEARCH_BACKENDS` | Поисковые движки через запятую | `duckduckgo` |
| `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` | Для режима `LLM_PROVIDER=yandex` | — |
| `DJANGO_DEBUG` | Режим отладки Django | `True` |

Ключи GigaChat выдаются бесплатно на [developers.sber.ru](https://developers.sber.ru) после регистрации приложения.

> Файл `.env` содержит секреты и не попадает в git — он перечислен в `.gitignore`.

## Работа с файлами

Кнопка 📎 (или перетаскивание файлов в окно браузера) позволяет приложить к
вопросу до четырёх файлов по 10 МБ:

| Тип | Форматы | Как читается |
|---|---|---|
| PDF | `.pdf` | извлечение текстового слоя (pypdf) |
| Word | `.docx` | абзацы и таблицы (python-docx) |
| Текст | `.txt`, `.md`, `.rtf`, `.csv`, `.json`, `.html`, `.xml`, `.log` | автоопределение кодировки (UTF-8 / cp1251 / cp866) |
| Изображения | `.png`, `.jpg`, `.gif`, `.bmp`, `.webp`, `.tiff` | OCR Tesseract — требует установки (см. ниже) |

Извлечённый текст попадает в контекст модели как «документы пользователя» и
цитируется ссылками вида `[Д1]`, `[Д2]` — отдельно от интернет-источников
`[1]`, `[2]`. Файлы не сохраняются на диск: текст читается из памяти, в истории
диалога остаются только имя и тип файла.

**Распознавание текста с фото и сканов** требует Tesseract OCR:

1. Установите [Tesseract для Windows](https://github.com/UB-Mannheim/tesseract/wiki),
   при установке отметьте языковой пакет **Russian**.
2. Добавьте каталог установки в `PATH`, либо пропишите путь явно:
   ```python
   import pytesseract
   pytesseract.tesseract_cmd = r"C:\Program Files\Tesseract-OCR\tesseract.exe"
   ```

Без Tesseract картинки принимаются, но вместо текста модель получает пометку о
недоступности OCR; текстовые документы, PDF и DOCX работают в любом случае.

## Интерфейс

- Стартовый экран с приветствием и строкой ввода
- Прикрепление документов и фото (📎 или перетаскивание), вложения видны как «чипы»
- Ответы с маркерами источников `[1]`, `[2]` и кликабельным списком ссылок под каждым ответом
- Индикатор подготовки ответа, Enter — отправить, Shift+Enter — новая строка
- Прокрутка ленты не «дёргается» при появлении ответа; если открутил вверх — появляется кнопка вниз
- Кнопка «Очистить» начинает диалог заново

## Ограничения

- Компетенция — право Российской Федерации.
- Ответы носят справочный характер и не заменяют консультацию юриста.
- Качество ответа зависит от доступности найденных страниц: часть сайтов закрыта от ботов или собрана на JavaScript и не отдаёт текст.
- GigaChat использует сертификат, корень которого не входит в стандартные хранилища, поэтому для его запросов отключена проверка TLS. Для продакшена следует подключить официальный корневой сертификат Минцифры вместо отключения проверки.

## Лицензия

Материалы проекта доступны свободно. Референсы интерфейса и рабочие заметки в папке `0/` не являются частью приложения.
